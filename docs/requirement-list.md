# Requirement List
## Functional Requirements
| No. | Requirement | Use Case(s) |
|---|---|---|
| 1 | 가입을 신청한 회원의 ID, 비밀번호, 전화번호를 기억할 수 있어야 한다.  | 회원 가입 |
| 2 | 회원과 관리자는 ID와 비밀번호로 시스템에 로그인할 수 있어야 한다.  | 로그인 |
| 3 | 회원과 관리자는 로그아웃할 수 있어야 하며, 이 때 시스템 접속이 종료되어야 한다. | 로그아웃 |
| 4 | 관리자는 자전거 정보를 등록할 수 있어야 한다. | 자전거 등록 |
| 5 | 회원은 특정 자전거를 대여할 수 있어야 한다. | 자전거 대여 |
| 6 | 회원은 현재 대여 중인 자전거 리스트를 조회할 수 있어야 한다. | 자전거 대여 정보 조회 |
