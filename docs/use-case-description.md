# Use Case Description

## Use Case Description
| Use Case | Description |
| 회원 가입 | 비회원은 서비스 이용을 위해 회원가입을 해야 한다. 회원가입 시 ID, 비밀번호, 전화번호를 필수로 입력해야 한다. |
| 로그인 | 사용자는 ID와 비밀번호를 입력하여 로그인할 수 있다. 이 때 관리자는 주어진 ID(admin)와 비밀번호(admin)로 로그인할 수 있다. |
| 로그아웃 | 로그인한 사용자는 로그아웃을 할 수 있다. 로그아웃 시 로그인한 사용자의 시스템 접속이 종료된다. |
| 자전거 등록 | 관리자는 새로운 자전거 정보를 등록할 수 있다. 이 때 자전거 ID, 자전거 제품명을 입력해야 한다. |
| 자전거 대여 | 회원은 대여할 자전거의 ID를 입력하여 그 자전거를 대여할 수 있다. |
| 자전거 대여 정보 조회 | 회원은 자신이 현재 대여 중인 모든 자전거의 자전거 정보 리스트를 조회할 수 있다. 리스트의 각 항목은 자전거 ID, 자전거 제품명을 포함한다.


1. 회원 가입 

| Actor Action | System Response |
|---|---|
| 1. 회원가입에 해당하는 메뉴 번호와 ID, 비밀번호, 전화번호를 입력한다. | 2. ID, 비밀번호, 전화번호를 출력한다. |

2. 로그인

 | Actor Action | System Response |
 |---|---|
 | 1. 로그인에 해당하는 메뉴 번호와 사용자의 ID, 비밀번호를 입력한다. | 2. ID, 비밀번호를 출력한다. |

 3. 로그아웃
 
 | Actor Action | System Response |
 |---|---|
 | 1. 로그아웃에 해당하는 메뉴 번호를 입력한다. | 2. 로그아웃한 사용자의 ID를 출력하고 로그아웃한 사용자의 시스템 접속을 종료한다. |


 4. 자전거 등록

 | Actor Action | System Response |
 |---|---|
 | 1. 자전거 등록에 해당하는 메뉴 번호와 등록할 자전거의 ID, 제품명을 입력한다. | 2. 등록된 자전거의 ID와 제품명을 출력한다. |


 5. 자전거 대여

 | Actor Action | System Response |
 |---|---|
 | 1. 자전거 대여에 해당하는 메뉴 번호와 대여할 자전거의 ID를 입력한다. | 2. 입력된 자전거 ID와 일치하는 자전거의 자전거 ID, 자전거 제품명을 출력한다. |


 6. 자전거 대여 정보 조회

 | Actor Action | System Response |
 |---|---|
 | 1. 자전거 대여 정보 조회에 해당하는 메뉴 번호를 입력한다. | 2. 회원이 현재 대여 중인 자전거 리스트를 출력한다. 각 항목은 자전거 ID, 자전거 제품명을 포함한다. |
